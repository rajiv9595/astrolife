# ASTROLIFE V2 — PHASE 8 UNCERTAINTY

## 1. UNKNOWN propagation (§20)

Missing Dasha / transit / Jaimini / required yoga each yield UNKNOWN signals,
UNKNOWN activation/timing, and enumerated `unknowns`. Golden proof: HEALTH
(UNSUPPORTED), EDUCATION (NOT_FORMED, no windows), timing-absent entries.

## 2. Core identities (tested)

MISSING ≠ NOT_FORMED (formation engine: absent outcomes → UNKNOWN).
MISSING ≠ INACTIVE (activation engine: absent layers → UNKNOWN).
MISSING ≠ NO_EVENT (no hypothesis claims absence from missing data).

## 3. Evidence states (§§28, 38 — NOT probability)

EVIDENCE_COMPLETE (all required present + evidenced), EVIDENCE_PARTIAL
(only optional-layer gaps), EVIDENCE_INSUFFICIENT (required gaps or
unsupported coverage), EVIDENCE_CONFLICTED (disagreements present).
Documented in-code and here as non-statistical.

## 4. Ranks (§27 — ordering, not scoring)

PRIMARY (formed + active + multi-system, no exclusions),
SECONDARY (formed + active otherwise, incl. exclusion-present with reason),
ALTERNATIVE (formed, no active window), CONFLICTING (disagreement preserved),
UNKNOWN (undecidable). Deduplication collapses only identical (event,
profile, versions, ancestry, window, tradition) tuples.

## 5. Outcome firewall (§§29–30)

Engine emits EVENT_WINDOW candidates ("timing candidate", "potential
window", "astrologically indicated period", "multiple systems converge",
"evidence is incomplete", "systems conflict"). Forbidden: "will definitely
happen", "guaranteed", "certain", "100%", "you will" — enforced by strict
validator over every candidate and warning string.
